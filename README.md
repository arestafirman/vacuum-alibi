# The Vacuum's Alibi

An entry for [The Vacuum's Alibi: One Line, 200 Characters](https://make.fun/c/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7) on [make.fun](https://make.fun).

A robot vacuum explains, in one deadpan line, why it has been vacuuming around the same ketchup stain for three weeks: its LiDAR classified the stain as a load-bearing wall, and the map is law.

`main.ts` writes the single line to `/output/entry.txt`.
